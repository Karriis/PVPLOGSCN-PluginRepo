# PVPLOGSCN 插件安装库

本仓库公开提供 Dalamud 插件库清单和已构建的安装包。PVPLOGSCN 源码保存在私有仓库。

在 Dalamud 的 `Experimental` → `Custom Plugin Repositories` 添加：

```text
https://raw.githubusercontent.com/Karriis/PVPLOGSCN-PluginRepo/main/pluginmaster.json
```

插件连接 [pvpdata.com](https://pvpdata.com) 正式服务。首次使用时需在插件内同意隐私协议并绑定网站账号。

本插件基于 [wrath16/PvpStats](https://github.com/wrath16/PvpStats) 重写，保留其 MIT 许可与原项目署名。许可文本见 [LICENSE.txt](LICENSE.txt)。
